FIND YOUR KEY IN ONE SEARCH

Every file ends in a search tag like KEY-Bminor, KEY-F#major, KEY-Ebminor, KEY-Adorian. Type the tag into your DAW browser (Ableton, FL, Logic, Bitwig) and only that key shows up: KEY-Bminor never matches B-flat. Every file also carries the key spelled out, (G Lydian), so typing G Lydian or Glydian both find it. Search a progression too: i-VI-III-VII.
